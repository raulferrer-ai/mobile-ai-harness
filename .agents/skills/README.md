# Skills index

Load a skill on demand by reading `.agents/skills/<name>/SKILL.md` only when it is relevant to the task.
Skills are procedures; technology specifics live in `docs/stack.md` and `.agents/references/`.

Workflow
- `workflow-planner`: split a spec into verifiable steps per platform and check parity before coding.
- `workflow-implementer`: implement increments cleanly with the build-sensor-fix loop.
- `workflow-validator`: audit finished work against the spec and contracts before the gate.
- `feature-spec-writer`: write or refine a Gherkin spec and register it on the board.
- `flywheel-recorder`: turn a deviation into a log entry plus a rule, scenario or sensor.
- `git-governance`: keep commits and the working tree clean, scoped and verified.

Platform and quality
- `ios-architecture-swiftui`: iOS layering, view models, concurrency and repository boundary.
- `android-architecture-compose`: Android layering, UDF, Compose and repository boundary.
- `design-system-parity`: tokens, components and states aligned across platforms.
- `mobile-data-permissions`: persistence, migrations, media, permissions, reminders.
- `mobile-testing-harness`: fast deterministic unit, repository and UI tests.
- `mobile-accessibility-localization`: accessible, localizable UI and copy.
- `mobile-security-privacy`: secrets, secure storage, data minimization, logging.

Harness
- `harness-maintainer`: evolve skills, scripts, contracts and the version baseline safely.
